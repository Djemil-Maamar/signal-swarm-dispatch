# Signal Swarm Dispatch

Built web Mail & SMS sender platform for acees to site gsm network with supabase  & KDEConnect and integrated automation for batch notification delivery.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://signal-swarm-dispatch.lovable.app

## Build with Lovable
